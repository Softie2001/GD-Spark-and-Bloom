GD SPARK & BLOOM — INTERACTIVE WEBSITE CONCEPT

Open index.html in a modern browser. For reliable file/image loading, run a local web server in this directory, e.g.:
  python -m http.server 8080
then visit http://localhost:8080

Included:
- Responsive storefront: home, shop, about, contact
- Guest cart, coupon checkout, receipt upload, no customer login
- Admin preview: products, sales prices, stock, visibility, bestseller tags, coupons, banner scheduling, order review, WhatsApp message templates, status workflow, bank settings
- Browser-local demo storage for product and order information; cart stored per browser session
- Original GD Spark & Bloom logo and branded bag image uploaded by client

IMPORTANT — NOT PRODUCTION READY
- Admin has NO authentication or access control. Do NOT publish the admin route publicly as-is.
- Orders, receipts and settings are stored only in the local browser; NOT transmitted to the vendor, synced across devices, or backed up.
- Bank details are placeholders and must be verified before processing real payments.
- Product listings and images are illustrative placeholders, not confirmed inventory.
- External botanical images are demo placeholders; replace with approved product photos and check usage rights.
- Confirm Instagram and TikTok URLs with vendor before publication.
- Production needs backend database, private receipt storage, server-side validation, admin authentication, secure order creation, anti-spam, rate limiting, privacy notice/retention, and a deployed domain.
- WhatsApp opening a compose window does not automatically send a message; the vendor must press Send.
- Manual payment verification must rely on bank records, not receipt pictures alone.
