GD SPARK & BLOOM - v2 website demo

Upload ALL files together to the SAME GitHub Pages folder (including site.js, site.css and assets/). Do not upload only index.html.

Pages: index.html, shop.html, about.html, contact.html, cart.html, checkout.html, payment.html, success.html.

Admin preview: admin.html (intentionally not in the customer navigation). Warning: this is NOT access-protected. It is a frontend-only demo; do not publish any real customer data or bank credentials.

Customer order: Shop → Cart (review, coupon) → Checkout (customer/delivery details) → Payment (transfer, receipt).

Data is browser-only localStorage, not shared between browsers or vendor devices. Real payments are not enabled.
